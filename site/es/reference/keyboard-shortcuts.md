# Atajos de teclado

Los atajos usan `Cmd` en macOS y `Ctrl` en Windows y Linux (mostrados aquí como `Ctrl/Cmd`).

## Notas y edición

| Atajo | Acción |
| --- | --- |
| `Ctrl/Cmd+N` | Nueva nota |
| `Ctrl/Cmd+Shift+N` | Nueva carpeta |
| `Ctrl/Cmd+Shift+D` | Nota diaria |
| `Ctrl/Cmd+S` | Guardar |
| `Ctrl/Cmd+F` | Buscar en la nota |
| `Ctrl/Cmd+H` | Reemplazar en la nota |
| `Ctrl/Cmd+I` | Importar |
| `Ctrl/Cmd+E` | Exportar |

## Vistas

| Atajo | Acción |
| --- | --- |
| `Ctrl/Cmd+G` | Vista de grafo |
| `Ctrl/Cmd+K` | Vista Kanban |
| `Ctrl/Cmd+Shift+K` | Knowledge Insights |
| `Ctrl/Cmd+Shift+F` | Modo concentración / escritura |
| `F8` | Mostrar/ocultar lista de notas |
| `F9` | Mostrar/ocultar barra lateral |

## Búsqueda y comandos

| Atajo | Acción |
| --- | --- |
| `Ctrl/Cmd+P` | Paleta de comandos |
| `Ctrl/Cmd+O` | Selector rápido |

## Herramientas

| Atajo | Acción |
| --- | --- |
| `Ctrl/Cmd+Shift+L` | Hacer nota privada/pública |
| `Ctrl/Cmd+Shift+H` | Historial de notas |
| `Ctrl/Cmd+Shift+G` | Panel de sincronización Git |
| `F1` | Atajos de teclado |

También puedes llegar a cualquier comando desde la paleta de comandos (**Ctrl/Cmd+P**).
