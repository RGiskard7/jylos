# Canvas

The Canvas editor opens and edits Obsidian-compatible `.canvas` files on an infinite, pan/zoom surface.

## What you can do

- Create, move, resize and colour text, link and group nodes.
- Connect and delete edges, with arrowheads.
- Create new canvases.

## Safety

Saves round-trip safely: unknown fields are preserved, so a canvas produced or edited by another Obsidian-compatible tool stays intact.
