# Keyboard Shortcuts

Shortcuts use `Cmd` on macOS and `Ctrl` on Windows and Linux (shown here as `Ctrl/Cmd`).

## Notes and editing

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+N` | New note |
| `Ctrl/Cmd+Shift+N` | New folder |
| `Ctrl/Cmd+Shift+D` | Daily note |
| `Ctrl/Cmd+S` | Save |
| `Ctrl/Cmd+F` | Find in note |
| `Ctrl/Cmd+H` | Replace in note |
| `Ctrl/Cmd+I` | Import |
| `Ctrl/Cmd+E` | Export |

## Views

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+G` | Graph view |
| `Ctrl/Cmd+K` | Kanban view |
| `Ctrl/Cmd+Shift+K` | Knowledge Insights |
| `Ctrl/Cmd+Shift+F` | Focus / writing mode |
| `F8` | Toggle notes list |
| `F9` | Toggle sidebar |

## Search and commands

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+P` | Command palette |
| `Ctrl/Cmd+O` | Quick switcher |

## Tools

| Shortcut | Action |
| --- | --- |
| `Ctrl/Cmd+Shift+L` | Make note private/public |
| `Ctrl/Cmd+Shift+H` | Note history |
| `Ctrl/Cmd+Shift+G` | Git sync panel |
| `F1` | Keyboard shortcuts |

You can also reach any command from the command palette (**Ctrl/Cmd+P**).
