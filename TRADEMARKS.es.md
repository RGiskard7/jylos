# Política de marca

English: [TRADEMARKS.md](TRADEMARKS.md). Español: este archivo.

El código fuente de Jylos está licenciado bajo la [Licencia MIT](LICENSE).

El nombre Jylos, el logo, los iconos y el branding visual **no** están licenciados bajo
la Licencia MIT. Son marcas/activos de marca del proyecto Jylos (Eduardo Díaz Sánchez) y
se rigen por esta política, separada de la licencia del código.

## Puedes

- Hacer fork, modificar y redistribuir el código bajo la Licencia MIT, incluido uso
  comercial.
- Referirte a Jylos por nombre para describir compatibilidad — por ejemplo "Plugin para
  Jylos" o "Compatible con Jylos" — siempre que la afirmación sea veraz y no implique
  respaldo oficial.
- Usar el nombre Jylos en tutoriales, reseñas, documentación y debate.

## No puedes

- Usar el nombre Jylos, el logo, los iconos o el branding para dar a entender que un
  fork, plugin, build, paquete, servicio o app es oficial, respaldado o mantenido por el
  proyecto Jylos, salvo que realmente lo sea.
- Publicar un build modificado bajo el nombre Jylos de forma que pueda confundirse con
  una versión oficial.
- Usar un nombre o logo confusamente similar.
- Etiquetar algo como "Official Jylos Plugin" (o similar) salvo que esté publicado o
  aprobado explícitamente por el mantenedor de Jylos.

Los forks deben adoptar nombre y branding distintos salvo permiso explícito.

## Alcance

Esta política aplica de aquí en adelante y no altera los términos MIT ya concedidos a
ninguna versión del código publicada previamente — esas siguen MIT, sin cambios.
